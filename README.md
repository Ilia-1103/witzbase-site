# WitzBase website

Public informational website for the WitzBase desktop application.

English and German pages describe the application, privacy practices and terms.
No application source, databases, media libraries, credentials or OAuth tokens
are included in this repository.

## Publish with GitHub Pages

In repository Settings → Pages, select:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

The expected public address is https://ilia-1103.github.io/witzbase-site/

Google Cloud Branding URLs after deployment:

- Home: https://ilia-1103.github.io/witzbase-site/
- Privacy: https://ilia-1103.github.io/witzbase-site/privacy.html
- Terms: https://ilia-1103.github.io/witzbase-site/terms.html

German versions are available in de.html, privacy-de.html and terms-de.html.

Publishing these pages does not itself verify the OAuth application.
Google may require proof of site ownership and additional application changes.
